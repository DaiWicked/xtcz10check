## 加密文件特征
- 文件头前 20 字节固定为：`E7 DD 3B 60 6F 74 A4 E3 64 C4 C8 7E 32 2D A9 A3 41 A3 9B E5`
- 整个文件（或前32字节）经过双重 XOR 加密，无独立明文头部

### 2. 初始参数（固定，不从文件读取）
```python
class XtcXorHdrStruct:
    encrypt: int = 1      # 未使用
    index: int = 41       # 第二个 XOR 的 key_table 索引，每64字节+1
    count: int = 41       # 循环计数器，每64字节+1，达256重置
    unknow4: int = 0      # key_index 偏移量
```

### 3. 解密流程
```
输入：加密文件路径
输出：原地覆盖解密（或输出到新文件）

1. 确定解密范围：
   - 文件大小 > 32768 (0x8000) 字节 → 只解密前 32 字节
   - 文件大小 ≤ 32768 字节 → 解密整个文件

2. 逐字节解密（cur 从 0 到 buffer_size-1）：
   a. key_index = (cur + unknow4) % 64       # 注意是 %64，不是 %256
   b. buffer[cur] ^= key_table[key_index]    # 第一次 XOR
   c. buffer[cur] ^= key_table[hdr.index]    # 第二次 XOR
   d. 如果 key_index == 0（即 cur 是 64 的倍数）：
      - hdr.count += 1
      - hdr.index += 1
      - 如果 hdr.count >= 256：
          hdr.count = 0
          hdr.index = 0
   e. cur += 1

3. 写回文件（原地覆盖）
```

### 4. 算法等价简化
由于 XOR 满足结合律，两次 XOR 等价于一次：
```python
effective_key = key_table[cur % 64] ^ key_table[hdr.index_at_cur]
buffer[cur] ^= effective_key
```
其中 `hdr.index_at_cur` = 41 + (cur // 64)，直到 count 达到 256 后重置。

## 注意事项
1. **原地解密**：MIO-KITCHEN 原实现直接覆盖原文件，使用前务必备份
2. **大文件限制**：>32KB 的文件只解密前 32 字节（本批 XML 均 <32KB，全文解密）
3. **参数固定**：所有加密文件使用相同初始参数（index=41, count=41, unknow4=0），不依赖文件头
4. **UI 小 bug**：`plugin_decrypt_xtc_xml.py` 中文件选择器用的是 `getExistingDirectory`（选目录）而非选文件
