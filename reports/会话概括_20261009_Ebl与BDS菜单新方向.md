## 二、当前核心结论

### 已确认 ✅
1. **imagefv 方向可以停止**：只有位图，无代码，无消费者，且要过 PAS
2. **Ebl 是不经 PAS 的引导期代码执行通道**：mountfv + start
3. **BDS 菜单是工程模式入口**：有关 Secure Boot / Debug Policy 的开关
4. **toolsfv 等空分区是潜在的工具装载位置**：不刷、不在 AVB 范围
5. **UEFI 变量存储是新高价值方向**：可能用 EDL 直接种入 DebugPolicy 变量

### 未解决 ❓
1. **BDS 菜单是否可达？由什么门控？**
2. **Ebl 是否有非交互调用路径？**（启动脚本/配置）
3. **toolsfv 是否会被自动挂载？fv2/fv3 设备分配逻辑？**
4. **UEFI 变量存在哪里？uefivarstore 分区还是 RPMB？**
5. **DebugPolicy/SecureBoot 变量的消费者是谁？**
